Skeleton To Nigromant -- raylib version

Made by Daniel González.

## About the project

This game was originally made with Unreal Engine 5 and it's available on itch.io (https://epicpantss.itch.io/skeleton-to-nigromant). The objective of this Project is to use raylib and C++ to convert the game to a 2D format, preserving its core mechanics and with a focus in clean gameplay architecture.

## Features

- Turn-based movement: the world only advances when the player acts
- Enemies with simple AI
- Traps and tiles that can be transformed to the player's advantage
- Levels loaded from custom text files
- Undo / restart level
